# 鼓手节拍器（PWA）

离线可用的架子鼓节拍器：Web Audio 采样级精确调度、多段落练习计划（含速度渐变）、自定义重音型、随机静音训练、可编辑并实际播放的鼓谱型（Kick/Snare/Hi-Hat 步进网格）、谱面参考（导入图片/PDF）、配乐练习（导入音乐 + Tap 定速）。

## 本地运行

```bash
node scripts/serve.js
```

然后浏览器打开 http://localhost:5173 （手机要访问同一局域网内的这台电脑 IP + 端口）。首次进入会看到"点击开始"遮罩——浏览器强制要求手动点一下才允许播放音频，点一下就行。

## 部署成真正可安装的 PWA

把整个文件夹丢到任意支持 HTTPS 的静态托管（GitHub Pages / Vercel / Netlify / 自己的 Nginx 都行）即可。**必须是 HTTPS**（或 localhost），否则 Service Worker 和 Wake Lock 这些 API 都不会启用。部署后手机浏览器打开，选"添加到主屏幕"，就是一个图标、全屏、离线可用的 App 体验。

## 目录结构

- `js/rhythmMath.js` —— 纯节奏数学（BPM/渐变/拍号推进），不依赖浏览器环境，`test/rhythmMath.test.js` 用 Node 直接测试，跑法：`node test/rhythmMath.test.js`
- `js/audio.js` —— Web Audio 引擎，开局在内存里合成所有 click/鼓声音色（不需要下载音频文件，天然离线可用）
- `js/engine.js` —— 播放调度器：音频调度锚定 `AudioContext.currentTime`（采样级精确），UI/振动反馈通过 `setInterval` 轮询事件队列同步触发（**特意没用 `requestAnimationFrame`** —— 测试过程中发现 rAF 在某些场景会停止触发，导致音频照常播放但视觉/振动反馈静止不动；`setInterval` 更可靠，见文件头注释）
- `js/db.js` / `js/storage.js` —— IndexedDB 存储层（练习计划、鼓谱型、导入的谱面/音乐文件、设置）
- `js/views/*.js` —— 四个 Tab 的界面逻辑
- `service-worker.js` —— 离线缓存，改了任何 `js/`、`css/` 文件后记得把 `CACHE_NAME` 版本号加一，否则用户/你自己本地测试时会一直吃旧缓存（这个坑在开发过程中真的踩到了一次）

## 我在这个会话里已经验证过的

用内置浏览器工具实际跑起来点过一遍，不是只看代码：
- 单元测试：14 项节奏数学断言全绿（BPM渐变插值、拍号推进、小节/段落循环、静音随机等）
- 快速模式播放：确认 `AudioContext` 正确 resume、节拍灯随音频时钟同步高亮、BPM 数字实时刷新
- 练习计划编辑器：新建、开启速度渐变、编辑重音型，关闭再重新打开验证数据确实存进了 IndexedDB（不是假保存）
- 鼓谱型编辑器：网格点击编辑、预览播放（Engine 复用同一套调度器）、步进光标跟着音频走、数据持久化验证
- 谱面/配乐/设置页：音量滑块联动 `AudioEngine` 增益节点并写入设置、备份导出数据结构正确
- 所有页面来回切换 tab 期间控制台零报错

## 还没能在这个会话里验证、需要你自己在真机上过一遍的

- **导入图片/PDF/音乐文件**：这需要系统原生文件选择器，我这边的自动化浏览器工具没有文件上传能力，代码逻辑是标准的 `<input type="file">` + `FileReader`/`Blob`，但没有用真实文件跑过，麻烦你实际导入一张图和一首歌试一下
- **真机 Wake Lock 是否生效**：不同手机浏览器支持程度不一样（iOS Safari 16.4+ 才支持），拿起鼓棒别看屏幕练一会儿，看是否真的没自动黑屏
- **蓝牙音箱/耳机延迟**：前面讨论过这是硬件级限制，建议先用有线或手机外放测出"基准感觉"，再对比蓝牙差多少
- **多设备/长时间抖动**：我这边验证的是调度逻辑正确、事件不丢，没条件做"连续练习 30 分钟测漂移"这种长时间真机实测，如果你发现明显跑偏，`js/engine.js` 里的 `TICK_MS`/`DRAIN_MS`/`LOOKAHEAD_SEC` 是可调参数

## 内置练习内容：完整音符时值表

`data/rhythm-value-chart.json`（由 `node scripts/gen_rhythm_chart.js` 生成，脚本内有落点合法性校验）：45 个鼓谱型 + 5 个练习计划，全部编在 Snare 音轨、4/4 一小节、默认 80 BPM × 4 小节/段。App 首次启动自动写入（`Storage.seedBuiltins`）；以后改了这个 JSON，要把 `storage.js` 里的 `SEED_VERSION` 和 `service-worker.js` 的 `CACHE_NAME` 各加一，已安装的 App 才会拿到更新。分类：基础时值 / 十六分单拍组合（1 e & a 全 15 种）/ 三连音与六连音 / 休止符 / 切分与综合。鼓谱编辑器支持 8/12/16/24/32 步（12=三连音，24=六连音）。

## 已知设计取舍（不是遗漏，是讨论后主动排除的）

- 不做自动扒谱（ML 门槛高、准确率不可控）
- 不做五线谱渲染引擎，谱面就是你导入的图片/PDF 原样展示
- 谱面和节拍播放不做精确同步，纯展示参考
- 不做练习记录/进度追踪
- 不做云同步，纯本地 IndexedDB，用"数据备份"里的导出/导入功能手动搬家
